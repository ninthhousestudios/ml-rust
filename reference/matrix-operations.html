Matrix Operations

Quick reference for the ml-rust Matrix type

Storage: Row-Major

A matrix is stored as a flat Vec<f64>, rows concatenated back-to-back.

[ a b c ]
[ d e f ]   →   memory: [a, b, c, d, e, f]

flat_index = r × cols + c

This is the single formula behind get(r, c) and set(r, c, v).

Operations

Transpose

Swap rows and columns: result(c, r) = original(r, c).

Shape: (m × n) → (n × m)

let t = m.transpose();

Matrix Multiply

Dot each row of self with each column of other.

Shape: (m × n) · (n × p) → (m × p). Inner dimensions must match.

result(i, j) = Σ_k self(i, k) × other(k, j)

let c = a.matmul(&b);

Cache-friendly loop order: R → K → C (not R → C → K). Keeps access to other sequential in memory.

Subtract

Elementwise subtraction. Shapes must match.

let diff = a.subtract(&b);

Scalar Multiply

Multiply every element by a scalar.

let scaled = m.scamul(0.5);
